# AI 작업 투명성

Character Room Builder는 OpenAI Codex와 Anthropic Claude Code의 도움을 받아 기획·작성되었다.

## 공개 원칙

- AI 코딩 도구의 실질적인 도움은 사이트 푸터, README, 향후 릴리스 노트에서 지속적으로 밝힌다.
- 도구의 제안은 유지관리자가 검토하고 채택 여부를 결정한다. 프로젝트의 최종 책임은 유지관리자에게 있다.
- 사용한 도구와 작업 방식은 숨기지 않으며, 중요한 변경에서는 사람의 판단과 도구의 보조를 구분해 기록한다.
- AI 코딩 보조와 생성형 이미지 사용 여부는 별개의 출처 정보로 관리한다.

## 이미지에 관한 현재 상태

현재 방과 가구 이미지는 생성형 이미지 모델의 출력물이 아니다. HTML5 Canvas에 작성된 공개 가능한 조형 규칙과 코드로 렌더링된다.

이 상태가 바뀌면 해당 에셋의 도구, 출처, 라이선스와 적용 범위를 별도로 명시해야 한다.
