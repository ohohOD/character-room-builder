# 아키텍처와 신뢰 경계

RoomDocument → 배치·충돌 규칙 → Canvas2D renderer → 화면·PNG 출력 순서로 구성한다. 렌더러는 Google, 계정, 네트워크를 알지 않는다. 외부 데이터 소스는 RoomDocument를 만들거나 저장하는 어댑터일 뿐이다.

## 예정 구조

- app: 화면과 상호작용
- lib/room: 방 스키마, 검증, 방 코드
- lib/renderer: 투영과 Canvas 렌더러
- lib/furniture: 파라메트릭 가구
- lib/style-packs: 팔레트·조명·재질
- lib/adapters: 로컬 파일·공개 시트 등 선택 연동

## 기본 모드

로그인과 네트워크 요청이 없다. 편집은 브라우저 메모리에서 수행하고 사용자가 명시적으로 방 코드, JSON, PNG를 내보낸다.

## 공개 시트 모드

읽기 전용이며 공개 가능한 전용 시트만 사용한다. 시트 ID는 비밀로 취급하지 않고 원본 운영 시트나 개인정보 열을 노출하지 않는다.

## 인증 연동

비공개 시트 자동 읽기 또는 쓰기는 계정 보안 기능이다. 별도의 위협 모델, 권한 최소화, 토큰 취소 절차가 준비될 때만 구현한다.

## provenance

모든 스타일 팩은 팩 ID·버전, 원안 작가와 구현자, 라이선스, 포함 에셋 출처, 생성형 이미지 모델 사용 여부를 가진다.
