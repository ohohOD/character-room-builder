# Furniture Foundry 로드맵

Furniture Foundry는 이 프로젝트의 기본 제작 도구다. Room Composer는 결과를 시험 배치하고 ROOM 코드로 공유하는 쇼룸이며, 공방 산출물의 유일한 사용처가 아니다.

## 현재 제공

- 입체·바닥·벽 조립면과 1×·2× 해상도
- 재료, 임의 HEX 표면색, 최근 10색의 기기 로컬 이력
- 결정론적 FURN1 코드와 URL fragment 공유
- 투명·종이 배경 PNG/WebP 단일 이미지
- 입체·바닥 가구의 4방향 PNG 스프라이트 시트
- 외곽선·재질 경계와 바닥 그림자 선택
- FURN1 가구의 Room Composer 배치와 ROOM1 포함

## 다음 편집 기반

1. 화면 확대·축소와 이동을 데이터 해상도 변경과 분리한다.
2. 정면·측면·평면·아이소메트릭 보기를 같은 FurnitureDefinition에 연결한다.
3. 실행 취소·다시 실행, 영역 선택, 이동·복제·반전·회전, 채우기와 스포이트를 추가한다.
4. sparse/chunk 상한을 정한 뒤 4× 이상의 조립 해상도를 추가한다.

## 이미지 변환 단계

1. 사용자가 고른 이미지를 메모리에서만 디코드한다.
2. 원하는 픽셀 크기, 팔레트 수, 투명도 임계값과 디더링을 미리 본다.
3. 벽·바닥 픽셀 패널, 밝기·알파 기반 부조, 참조면 중 결과를 고른다.
4. 앞·옆·위 실루엣 세 장은 교집합 기반 visual hull 복셀로 변환한다.
5. 원본·EXIF·로컬 경로는 저장하거나 공유 코드에 포함하지 않는다.

## 외부 활용 단계

- GIF와 애니메이션 WebP 회전 미리보기
- 8방향 또는 사용자 지정 프레임 시트
- 프레임 크기·바닥 기준점·방향을 담은 JSON
- FURN 코드와 라이선스를 함께 담은 다운로드 묶음

모든 단계는 로그인·서버 저장·자동 업로드 없이 동작하고, 생성형 이미지 모델을 에셋 파이프라인에 사용하지 않는다.
