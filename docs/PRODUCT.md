# 제품 기획 정본

## 한 줄 정의

커미션 이미지나 생성형 이미지 모델 없이도, 조형 문법과 절차적 Canvas 렌더링으로 일관되고 아름다운 캐릭터 방을 만드는 커뮤니티용 도구.

## 문제

자캐·TRPG·마이홈형 커뮤니티의 방 꾸미기는 매력적이지만 가구와 소품을 계속 이미지·도트 커미션으로 생산해야 한다. 품질과 시점을 맞추기 어렵고 다른 커뮤니티가 재사용하기도 힘들다. 생성형 이미지는 학습 출처와 창작자 권리 문제로 신뢰를 얻기 어렵다.

## 세 층

1. Furniture Foundry: 가구를 부품과 파라미터로 정의한다.
2. Room Composer: 사용자가 가구를 배치하고 방 코드를 저장한다.
3. Community Viewer: 커뮤니티별 데이터 소스에서 방을 읽어 표시한다.

## 첫 미술 방향

작은 종이 인형극 같은 3/4 아이소메트릭, 따뜻한 저채도 팔레트, 면의 명도 차, 왼쪽 위 고정 광원. 첫 공개 화면은 빈 편집기가 아니라 완성된 방이어야 한다.

## Google Sheets

시트를 사용하는 커뮤니티는 방·인벤토리·이벤트 해금 데이터를 저장하고 사이트에서 표시할 수 있다. 그러나 계정 권한을 요구하는 자동 연동은 기본 기능이 아니다.

- 기본: 방 코드를 사용자가 시트 셀에 직접 붙여넣기
- 공개: 민감정보가 제거된 전용 공개 시트를 읽기
- 고급: 별도 보안 검토를 거친 선택적 인증 어댑터

## 범위 밖

생성형 이미지 API, 필수 로그인, 실시간 다중 사용자 편집, 드래그마다 시트 저장, 스타일 팩의 무단 학습·모방.
