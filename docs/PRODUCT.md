# 제품 기획 정본

## 한 줄 정의

커미션 이미지나 생성형 이미지 모델 없이도 아이소메트릭 복셀 가구를 만들고, 편집 데이터와 범용 이미지로 가져갈 수 있는 로컬 우선 제작 도구.

## 문제

자캐·TRPG·마이홈형 커뮤니티의 방 꾸미기는 매력적이지만 가구와 소품을 계속 이미지·도트 커미션으로 생산해야 한다. 품질과 시점을 맞추기 어렵고 다른 커뮤니티가 재사용하기도 힘들다. 특정 방 편집기 안에서만 쓸 수 있는 결과물도 창작자의 활용을 제한한다. 생성형 이미지는 학습 출처와 창작자 권리 문제로 신뢰를 얻기 어렵다.

## 세 층

1. Furniture Foundry: 복셀·표면·픽셀 가구를 만들고 편집 데이터와 이미지로 내보낸다.
2. Room Composer: 만든 가구를 시험 배치하고 방 코드를 저장하는 쇼룸이다.
3. Community Viewer: 커뮤니티별 데이터 소스에서 방을 읽어 표시한다.

## 공방 중심 원칙

Furniture Foundry가 기본 진입점이며 Room Composer는 선택적 배치·공유 도구다. 공방에서 만든 결과는 이 사이트에 종속되지 않는다. 사용자는 FURN 코드로 편집 가능성을 보존하고, 투명 PNG·WebP, 4·8방향 시트, 회전 GIF·애니메이션 WebP처럼 다른 앱에서도 쓸 수 있는 결과물을 명시적으로 내려받을 수 있다. ZIP 제작 묶음은 이미지와 함께 FURN1, 프레임·바닥 기준점 JSON, 권리 표기 파일을 보존한다.

미디어 내보내기는 FurnitureDefinition을 변경하지 않는 렌더링 작업이다. 같은 정의, rendererVersion, 보기 방향과 내보내기 옵션은 같은 픽셀 결과를 만들어야 한다. 파일 생성은 브라우저 안에서 수행하며 자동 업로드나 원격 저장을 하지 않는다.

## 이미지에서 만드는 도구

사용자 제공 이미지를 브라우저 안에서 낮은 해상도로 축소·팔레트화해 벽·바닥 픽셀 패널, 밝기·알파 기반 복셀 부조, 앞·옆·위 실루엣 교차 기반 삼면도 조립 자료로 변환한다. 원본과 EXIF를 자동 저장·전송하지 않으며 변환 결과만 사용자가 선택해 가구 데이터에 포함한다. 3D 형태를 생성형 모델로 추측하지 않고 공개된 결정론적 변환 규칙을 사용한다.

## 첫 미술 방향

작은 종이 인형극 같은 3/4 아이소메트릭, 따뜻한 저채도 팔레트, 면의 명도 차, 왼쪽 위 고정 광원. 첫 공개 화면은 빈 격자가 아니라 완성 예시가 열린 공방과 깨끗한 결과 미리보기여야 한다.

## Google Sheets

시트를 사용하는 커뮤니티는 방·인벤토리·이벤트 해금 데이터를 저장하고 사이트에서 표시할 수 있다. 그러나 계정 권한을 요구하는 자동 연동은 기본 기능이 아니다.

- 기본: 방 코드를 사용자가 시트 셀에 직접 붙여넣기
- 공개: 민감정보가 제거된 전용 공개 시트를 읽기
- 고급: 별도 보안 검토를 거친 선택적 인증 어댑터

## 범위 밖

생성형 이미지 API, 필수 로그인, 실시간 다중 사용자 편집, 드래그마다 시트 저장, 스타일 팩의 무단 학습·모방.

## 제작 투명성

프로젝트는 OpenAI Codex와 Anthropic Claude Code의 도움을 받아 기획·작성되었음을 사이트와 저장소에서 지속적으로 밝힌다. 코딩 보조의 공개와 생성형 이미지 비사용 원칙은 각각 별도의 출처 정보로 관리한다.
