# 오픈소스 조사 메모

- Isomer(MIT): 아이소메트릭 좌표·면·색. 수학과 API를 참고해 자체 TypeScript 구현.
- Obelisk.js(MIT): 픽셀 아이소메트릭 블록과 팔레트 규칙 참고.
- D-Zone(ISC): 활동 데이터와 렌더 객체 분리 참고.
- Arcada(Apache-2.0): 가구 bounding box·배치·직렬화 참고.
- rot.js(BSD-3-Clause): 결정론적 공간 생성이 필요할 때 참고.
- seedrandom(MIT): 필요 시 로컬 RNG로 사용하며 전역 Math.random 변경 금지.

초기 구현은 외부 엔진 없이 Canvas2D로 시작한다. 코드 라이선스와 저장소 이미지 라이선스는 별개이므로, 외부 스프라이트는 명시적 에셋 라이선스가 없으면 사용하지 않는다.
